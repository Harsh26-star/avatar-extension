# Browser Buddy

## What is this ?

Browser Buddy is a Chrome Extension that adds a small animated avatar to your browser. The avatar stays on your screen while you browse or work, acting as a fun desktop companion.

## What it does ?

- Displays an animated avatar on web pages.
- Stays visible while you browse.
- Lightweight and easy to load as an unpacked Chrome extension.

## How to load it in Chrome ?

1. Download or clone this repository.
2. Open Chrome and navigate to `chrome://extensions/`.
3. Enable **Developer mode**.
4. Click **Load unpacked**.
5. Select the project folder.
6. The extension will be installed and the avatar will appear while you browse.
